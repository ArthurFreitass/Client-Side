Este curso de HTML básico oferece uma introdução prática à criação de páginas web, ideal para iniciantes. Você aprenderá a estruturar documentos web usando tags, parágrafos, listas, imagens, tabelas e links, resultando na construção de uma página funcional do zero.

  1. Objetivo: Capacitar o aluno a criar e estruturar páginas web estáticas, compreendendo a semântica e os elementos fundamentais da web.
  2. Para quem é: Iniciantes sem experiência prévia, aspirantes a desenvolvedores frontend ou quem deseja entender como sites são construídos.

Curso de CSS – Do Básico ao Avançado Aprenda a criar páginas web modernas, bonitas e responsivas utilizando CSS (Cascading Style Sheets). Neste curso, você vai entender desde os fundamentos — como seletores, cores, fontes e posicionamento — até técnicas avançadas, incluindo flexbox, grid layout.

Este curso foi desenhado para quem deseja iniciar na programação web, mesmo sem experiência prévia. Você aprenderá os fundamentos sólidos do JavaScript (JS), indo além do HTML e CSS para adicionar lógica, interatividade e dinamismo aos seus projetos.
